# Aurora

Aurora is our next-generation launch initiative. This repository is the coordination hub for the Aurora kick-off: it tracks the launch checklist, workstream issues, and early copy work. Goals for this release include a polished landing page, smooth billing integration, and a clean hand-off from legacy systems.

## Repository layout

- `main` — protected integration branch for the Aurora launch
- `feature/*` — short-lived workstream branches merged back into `main` via pull request

## Status

Kick-off review in progress. See the "Aurora launch checklist" issue for the current workstream breakdown.
